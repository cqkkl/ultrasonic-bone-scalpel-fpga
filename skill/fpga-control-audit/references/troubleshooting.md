# 触发条件与问题定位

| 观察或触发条件 | 优先核对 | 验证方式 |
| --- | --- | --- |
| 输出变化但PWM不随之变化 | 单位、固定占空比覆盖、地址映射、执行限幅 | 同步记录原始输出、限幅后输出与示波器占空比 |
| PID表现与公式不符 | 历史误差是否被局部常量覆盖 | 已知输入序列下逐拍核对误差和输出 |
| 模糊修正只在部分输入生效 | 量化分母括号、隶属度覆盖、输入饱和 | 测试区间端点、区间外输入和规则交界 |
| 扫频数据相对频率错位 | 设置频率、等待与取数顺序，帧标识 | 记录实际DDS指令与对应反馈帧 |
| FFT目标频点不合理 | 采样率、抽取率、N和输出索引 | 用已知频率输入与离线FFT比较 |
| 用管线延迟解释不同FFT索引 | 索引与tvalid是否随数据延迟 | 追踪带索引数据，不改写目标频率定义 |
| 电流不变但负载改变后功率变化 | 是否用电流替代功率，是否忽略相位 | 同窗U、I、相位与功率计比较 |
| 中断在初始化其他模块后失效 | 多次GIC初始化、多个实例、回调引用对象寿命 | 单源再多源中断测试，记录注册顺序 |
| 新编译器报告重复定义 | 头文件全局变量是否缺extern | 唯一定义，并用-fno-common构建 |
| FIFO丢帧或空读 | 有效吞吐率、反压、满空控制及复位 | 连续帧、帧号和边界测试；不只比较读写时钟 |
| 仿真可用，上板振荡 | Ts、单位、输入映射、延迟、b0与方向 | 相同记录输入对比，再低功率闭环 |
| 报告称已部署，仓库只有旧PI | 最终控制器是否在其他工作区或版本 | 定位提交、调用入口、构建和板测记录 |

这些条目来源于本项目审查或部署讨论。它们是定位线索，不是未经检查就可套用的修复结论。
